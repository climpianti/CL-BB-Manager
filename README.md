# CL B&B Manager

Integrazione personalizzata per Home Assistant destinata a B&B e piccole strutture ricettive.

**Stato: prototipo alpha, non usare su serrature di produzione.**

Gestione dinamica dei varchi, prenotazioni con codici temporanei, portale QR ospiti e comandi di apertura controllati. Il portale pubblico resta disabilitato per impostazione predefinita.

La documentazione e i sorgenti saranno aggiunti nel primo commit di sviluppo.
